# Очистка месячных продаж и остатков IEK

Офлайн-подготовка из ветки `baitc/alish`, перенесённая вместе с тестами. Скрипт не
подключён к расчёту заказа и не обучает модель. Полученные CSV — производное представление
имеющихся Excel, а не новый источник наблюдений.

Из корня проекта:

```bash
python -m pip install -r scripts/requirements-cleaning.txt
python scripts/clean_monthly_data.py
```

По умолчанию скрипт читает два месячных отчёта из `IEK/`. Исходные Excel не меняются.
Поддержка текущего комплекта проверена для IEK. Произвольный файл или выгрузка Systeme
Electric требует совпадения заголовков и отдельной проверки содержания.
Другие пути можно передать явно:

```bash
python scripts/clean_monthly_data.py --stock "остатки.xlsx" --sales "продажи.xlsx" --output-dir "data/clean/other"
```

Результаты в `data/clean/iek/` (повторный запуск обновляет эти три файла):

- `monthly_clean.csv`: одна строка на товар и месяц, объединение всех товаров обоих файлов.
- `quality_issues.csv`: адреса некорректных ячеек, отрицательные количества, удалённые точные дубли и несовпадающие названия.
- `quality_report.json`: статистика, пропуски, несовпадающие коды и ограничения данных.

| Поле CSV | Значение |
|---|---|
| product_code | Код товара, текст с сохранением ведущих нулей и `_` |
| product_name | Название из остатков; при отсутствии — из продаж |
| unit | Единица из остатков или продаж, если такой столбец есть; при отсутствии остаётся пустой |
| month | Первый день месяца в формате YYYY-MM-DD |
| sales_qty | Продажи за месяц; пропуск остаётся пустым |
| opening_stock_qty | Остаток на начало месяца; пропуск остаётся пустым |
| sales_row_present | В источнике продаж есть строка товара и столбец этого месяца |
| stock_row_present | В источнике остатков есть строка товара и столбец этого месяца |

Флаги присутствия не гарантируют, что само количество заполнено. Даты после очистки
не подтверждают полноту отчётного месяца. Скрипт не заменяет пропуски нулями,
не удаляет большие продажи как выбросы и не меняет знак отрицательных значений.
Ошибки количеств сохраняются в отчёте, а соответствующие значения CSV остаются пустыми.
Разные записи одного кода останавливают обработку: без склада или других признаков
нельзя безопасно решить, нужно ли их складывать. Точные дубли удаляются с записью в отчёт.

Строки и столбцы «Итого», а также служебные строки заголовка исключаются.
Начальные остатки нельзя суммировать по месяцам или считать актуальными на сегодня.
Месячные продажи и остатки нельзя использовать для точного определения дней stockout
или для выявления крупных заказов конкретного клиента.
Месячные матрицы не содержат склада или города. Каталог городов EKT не добавляет эту
размерность к данным. Привязку области отчётов к Алматы нужно подтвердить у владельца
выгрузки. Структура результата не совместима напрямую с `DATA_SOURCE=csv` приложения.
Для дальнейшей подготовки лагов и разделения периодов см. [ML_PREPARATION.md](ML_PREPARATION.md).

CSV хранит коды текстовыми полями, но Excel может автоматически изменить их при открытии.
Для последующей загрузки используйте явные типы:

```python
import pandas as pd

data = pd.read_csv(
    "data/clean/iek/monthly_clean.csv",
    dtype={"product_code": "string", "product_name": "string", "unit": "string"},
    parse_dates=["month"],
    keep_default_na=False,
    na_values={"sales_qty": [""], "opening_stock_qty": [""]},
)
```


## Связь с текущим сервисом и оценкой

После интеграции frontend сервис использует вход, постоянные заказы и отдельный
worker; запуск описан в [README](../README.md) и [DEPLOY](../docs/DEPLOY.md).
Производные таблицы этого скрипта остаются самостоятельным исследовательским
форматом. Для оперативного `DATA_SOURCE=csv` используйте
[контрольный sample](../data/sample_csv/README.md) с другим контрактом.

[Отдельный backtest](BACKTEST.md) уже измеряет текущую функцию прогноза на месячных
Excel двух поставщиков, с двумя политиками пустот. Он не обучает модель на этих
подготовленных файлах и не подтверждает общего преимущества над базовым методом.
Проверки всего проекта и текущей среды — [ПРИЕМКА](../docs/ПРИЕМКА.md).
