# Проверка 10 прогнозов IEK

Факты сверены с исходным Excel, средние пересчитаны по исходным месяцам. Для каждого месяца заново восстановлена историческая модель только на прошлом. Прогноз независимо получен обходом узлов и суммой значений листьев 160 деревьев. Сохранённые результаты совпали во всех 10 строках (расхождение меньше 1e-9).

Выбор: случайный, seed=42, после сортировки SKU; по 3 товара в штуках, 1 в метрах и 1 в упаковках в каждом из июля и августа. Примеры не отбирались по ошибке и не представляют весь каталог пропорционально.

Формулы: APE = |прогноз − факт| / факт × 100%; WAPE = сумма абсолютных ошибок / сумма фактов × 100% внутри одной единицы. Простое среднее считается только по известным неотрицательным месяцам. Пропуск не равен нулю.

## Пример расчёта

250200003_, июль: (3+2+6)/3 = 3,6667 шт. Факт — 3 шт. Модель — 6,709336 шт. Абсолютная ошибка модели — 3,709336 шт; APE = 3,709336/3 × 100% = 123,6445%. Ошибка среднего — 22,2222%.

Формула модели: max(0, базовое значение + сумма вкладов 160 деревьев) × масштаб. Вклады листьев уже учитывают learning_rate. Для этого примера: (1,1805285315992644 + 0,4968055362120197) × 4 = 6,709336271245137. Это не формула среднего за 3 месяца.
