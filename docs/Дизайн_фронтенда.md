# Дизайн фронтенда — ЭКТ Автозаказы

Тёмная деловая тема, ориентированная на плотные таблицы закупа и быстрый разбор «почему столько заказать».

---

## 1. Пользователь и контекст

Основной пользователь — **менеджер отдела закупа**: работает с сотнями позиций, ему важны плотность информации, читаемость чисел, мгновенное понимание срочности и обоснования. Отсюда — тёмный фон, моноширинные артикулы, цветовые статусы срочности, разворачиваемая раскладка.

---

## 2. Дизайн-система (токены)

CSS-переменные (`src/index.css`):

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#0f1420` | Фон приложения |
| `--panel` | `#171e2e` | Панели, карточки |
| `--panel-2` | `#1e2740` | Вложенные поверхности, инпуты |
| `--line` | `#2a3350` | Границы, разделители |
| `--text` | `#e6eaf2` | Основной текст |
| `--muted` | `#94a0ba` | Второстепенный текст, подписи |
| `--accent` | `#4c8dff` | Действия, ссылки, фокус |
| `--danger` | `#ff5c72` | Срочно / ошибки |
| `--warn` | `#ffb020` | Предупреждения / средняя срочность |
| `--ok` | `#33c27f` | Успех / утверждено |

Типографика — системный стек (`system-ui, Segoe UI, Roboto`); артикулы — моноширинный (`ui-monospace`).

---

## 3. Цветовые статусы срочности

| Статус | Цвет | Правило |
|---|---|---|
| 🔴 **Срочно** (`high`) | `--danger` | покрытие < срока поставки |
| 🟡 **Средне** (`medium`) | `--warn` | покрытие < горизонта (срок + период) |
| ⚪ **Плановый** (`low`) | `--muted` | запаса хватает / заказ не требуется |

Бейджи — пилюли с полупрозрачным фоном соответствующего токена (`.badge.u-high/.u-medium/.u-low`).

---

## 4. Компоненты и паттерны

- **Панель источника данных** — предупреждения о качестве данных (`.data-info`, `summary/details` в тонах `--warn`).
- **Контролы** — единый стиль `select`/`input` на `--panel-2` с `--line`, кнопка действия — `--accent`.
- **Итоги** — крупные числа, «срочных» акцентируются `--danger`.
- **Таблицы** — плотные строки, правое выравнивание чисел, утверждённая строка подсвечивается `--ok` (полупрозрачно), горизонтальный скролл на узких экранах.
- **Раскладка «почему?»** — чипы на `--bg` с границей `--line`; чипы «упущенный спрос» и «исключён опт» выделяются `--warn`.
- **Поле количества** — валидация: при ошибке рамка `--danger` (`.qty-invalid`), подсказка о кратности/MOQ.

---

## 5. Доступность и адаптив

- Видимый фокус для клавиатуры: `:focus-visible` — контур `--accent` с отступом.
- `aria-label` на секциях и навигации пагинации; `.sr-only` для скрытых подписей.
- Мобильная раскладка (`@media max-width: 640px`): контролы и итоги переносятся, кнопки экспорта на всю ширину, таблицы — со скроллом.

---

## 6. Принципы

1. **Плотность без шума** — максимум полезных чисел, минимум декора.
2. **Цвет = смысл** — только статусные значения (срочность, ошибки, успех).
3. **Прозрачность допущений** — предупреждения о данных всегда на виду, не спрятаны.
4. **Человек решает** — правки и утверждение всегда доступны; система только рекомендует.
