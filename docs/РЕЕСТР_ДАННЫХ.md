# Реестр данных, качество и воспроизводимость

Аналог «реестра» из шаблона, адаптированный под наш кейс: в выгрузках нет учётных записей — есть **реестр датасетов партнёра** и контроль их качества. Для передачи на продакшн.

---

## 1. Зачем это нужно

Расчёт опирается на реальные выгрузки 1С. Чтобы результат был воспроизводим и проверяем, зафиксированы: перечень файлов, как они читаются, какие допущения приняты и как обновлять данные перед новым заказом.

---

## 2. Реестр выгрузок

Папки `IEK/` и `Systeme electric/` — по 6 файлов каждая (маппинг в `app/data/excel.py::SUPPLIER_FILES`):

| Тип | IEK | Systeme Electric |
|---|---|---|
| Продажи (транзакции) | `Динамика продаж_2025-2026.xlsx` | `Динамика продаж_Syseme Electric_2025-2026.xlsx` |
| Месячные продажи | `Ежемесячные продажи … 2 года.xlsx` | `Ежемесячные продажи … SystemElectric 2024-2026.xlsx` |
| Месячные остатки | `Ежемесячные остатки … ИЭК.xlsx` | `Ежемесячные остатки SystemElectric 2024-2026.xlsx` |
| MOQ / кратность | `MOQ  ИЭК.xlsx` | `MOQ SystemElectric.xlsx` |
| Товары в пути | `Путь ИЭК 22.09.2026.xlsx` | `Товар в пути_SystemElectric на 22.09.2026.xlsx` |
| Сезонность | `Сезонность ИЭК.xlsx` | `Сезонность SystemElectric 2024-2026.xlsx` |

Дата снимка остатков/пути берётся из имени файла (`…22.09.2026…`).

## 4. Качество данных и допущения (`Dataset.warnings`, 15 шт.)

Ключевые (полный список — в ответе `/api/meta`):
- Клиентов в выгрузках нет → опт определяется по транзакциям, без объединения по клиенту.
- Точных интервалов stockout нет → скрытый спрос из месячных остатков не восстанавливается.
- Месячные отчёты и товары в пути отнесены к складу «Алматы» (нет разбивки по складам).
- Пустые месячные продажи = 0; пустые остатки = «неизвестно».
- Отрицательные транзакции = возвраты (исключены); отрицательный месячный итог ограничен нулём, `raw_qty` сохранён.
- Сроки поставки (IEK 21, Systeme 35 дн) — допущения, требуют подтверждения.
- Устаревшие снимки остатков (фолбэк по началу месяца) помечаются — обновить перед заказом.
- Формулы Excel — по сохранённым значениям; внешние ссылки не обновляются.

Счётчики некорректных/отфильтрованных ячеек — в `Dataset.metadata.counts`.

## 5. Как пересобрать / обновить

```bash
# 1. Обновить выгрузки в IEK/ и Systeme electric/ (те же имена файлов)
# 2. Кеш импорта инвалидируется автоматически по mtime/размеру
# 3. Пересчёт:
cd backend
./.venv/bin/python -c "from app.data.excel import ExcelDataSource; ExcelDataSource('..').load()"   # проверка загрузки
./.venv/bin/python -m pytest tests/test_excel_import.py -q     # структура
RUN_REAL_EXCEL_TESTS=1 ./.venv/bin/python -m pytest tests/test_excel_import.py -q   # smoke на реальных
```

Дату расчёта можно зафиксировать через `DATA_AS_OF=YYYY-MM-DD`, сроки поставки — через `IEK_LEAD_TIME_DAYS` / `SYSTEME_LEAD_TIME_DAYS`.
