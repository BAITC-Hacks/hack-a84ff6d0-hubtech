## 🚀 Быстрый старт

### Требования
- Node.js 18+
- Запущенный бэкенд FastAPI на порту 8017 (см. `backend/README.md`)

### Установка и запуск
```bash
npm install
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`.  
Vite автоматически проксирует `/api` на `http://localhost:8017`.

---

## 🛠 Доступные скрипты

- `npm run dev` — запуск локального dev-сервера с HMR
- `npm run build` — сборка production-бандла
- `npm run lint` — быстрая проверка линтером (oxlint)
- `npm test` — запуск тестов утилит заказа (`src/orderUtils.test.js`)
